#ParkEngine - "A Parking_Lot_Management_System using Design Patterns"

Parking lot automation system in Java.
- Instead of designing fancy UI I have just add simple console using AWT/Swing Framework.
- console app + AWT/Swing GUI on top of the same classes
- Design patterns: Factory, Observer, Strategy (parking / pricing / payment), Singleton Design pattern/
- Features: park vehicle, exit with billing + payment, search vehicle, live display boards

### 1. How I Used AI During Project Development

I used AI tools like ChatGPT and Claude to connect the User Interface (UI) to my existing ParkEngine project.

- First, I used AI to understand how to integrate a GUI with my existing Java backend.
- After understanding the integration process, I took only the required AWT/Swing source code generated by AI.
- Then, I customized that code and integrated it into my existing project according to my requirements.

### 2. What Mistakes Did AI Tools Make?

Initially, AI tools assumed that I had not developed any backend or existing source code.

- They generated a complete ZIP file containing an entirely new project instead of providing only the UI components.
- Although the suggested project structure was correct, it did not match my existing implementation.
- I reviewed the generated code, selected only the required UI components, and modified them to work with my existing classes and methods.
- I maintained my original backend logic instead of replacing it with AI-generated code.

### 3. What Would I Change or Improve?

Before uploading my project to GitHub, I would:

- Remove unnecessary and duplicate AI-generated files.
- Organize the source code into proper packages.
- Verify that the UI correctly communicates with the existing backend.
- Test the complete application.
- Add a README file explaining the project structure, features, and execution steps.

**My main focus was to use AI for assistance while keeping the original project logic and implementation under my control.**

## Project structure
```
src/
  program1017.java       original console app (unchanged)
  ParkingLotSetup.java   builds floors, spots, boards, gates for the GUI
  TextAreaStream.java    redirects System.out into the GUI log
  ParkEngineFrame.java   main window (AWT layouts + events, Swing components)
  ParkEngineApp.java     GUI entry point
```

## How to Run project in System
```
javac -d bin src/*.java
java -cp bin ParkEngineApp     # GUI
java -cp bin program1017       # console
```
